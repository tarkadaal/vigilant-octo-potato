# vigilant-octo-potato
A little playground for mentees, about flags

## Gifs!

You can draw pictures! Now let's make animations! An animation is just a bunch of pictures in a row. Make an animation of flags appearing!

The `write_gif.py` file is adapted from the Cario documentation. It will write an animated gif! Use this code as a base for your work. You do not need to understand every line; that's kind of the point of the exercise. Learn enough to do what you need.

Make a virtual environment, activate it, and then you can install all the libraries you need with:
`pip install -r requirements.txt`
